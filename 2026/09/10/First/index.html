🎉 零基础小白从零搭建 Hexo 博客踩坑全记录（附常用指令小抄）

前言

作为一个完全零基础的小白，从最初不知道命令行是什么，到最后成功把博客上线、换上漂亮的Reimu主题、改好头像，一路踩坑一路填，终于拥有了自己的网站：https://moanjinhuan.github.io。

这篇文章记录了我整个搭建过程、遇到的报错以及解决办法，希望帮到同样零基础的你！

🛠️ 第一阶段：环境准备

1. 注册 GitHub 账号

访问 https://github.com/，点击 Sign up 注册。记住你的用户名，这是你博客网址的一部分。

2. 安装 Git 和 Node.js

下载安装 Git 时，一定要注意这三个选项：

  • 默认编辑器：选 VS Code 或 Notepad。
  • PATH 环境变量：选 Git from the command line and also from 3rd-party software（第二项）。
  • 换行符转换：保持默认第一项即可。

使用 git clone git@github.com:… 报错 Connection refused。
✅ 解决办法： 改用 HTTPS 协议。

执行 hexo deploy 报错 Author identity unknown。

❌ 遇到的坑三（授权卡住）：

弹窗要求登录，浏览器授权卡死。
✅ 解决办法： 选择浏览器授权（Sign in with your browser）或直接使用 GitHub Token。去 GitHub 的 Settings -> Developer settings -> Personal access tokens 生成一个 Token（勾选 repo 权限），粘贴到密码框即可。

❌ 遇到的坑四（Pages 设置无法保存）：

在 GitHub 仓库 Settings -> Pages 里，选 main 分支后 Save 按钮点不了。
✅ 解决办法： 因为页面顶部提示“已从 main 分支构建”，说明已经配置好了，无需重复保存。

🧭 迷路指南

  • cd ~/Moanjinhuan：回到你的博客目录（每次打开 Git Bash 的第一件事）。
  • cd ..：退回到上一级文件夹。
  • ls：看看当前文件夹里有什么。
  • pwd：看看我现在在哪个路径。

🚀 偷懒

  • 按键盘上的 ↑（上箭头）：自动出现刚刚输入过的命令，不用手打！
  • 按键盘上的 Tab 键：自动补全文件名或路径，防止拼错。

💡 避坑总结

  1. 所有命令都在 Git Bash 里敲，不要打开 Node.js 去敲！

  2. 改外观（头像、标题、颜色）都在 _config.reimu.yml 里改。

  3. 改了配置一定要重新执行部署三连，并且浏览器按 Ctrl + F5 强制刷新。

  4. 非常重要：定期备份你的本地 Moanjinhuan 文件夹，因为你的文章源码全在这里！
